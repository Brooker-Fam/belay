Set up a phone for Belay

This page makes a freshly reset Android phone a Belay phone: it installs Belay and makes it the phone's manager (Android calls it the "device owner"), with the same steps and checks as android/scripts/provision.sh. It runs on this computer. The page talks to the phone over the USB cable, and nothing goes to the internet.

This page needs Google Chrome or Microsoft Edge (or another browser built on Chromium) on a computer. It talks to the phone over USB with WebUSB, which Firefox and Safari don't have, and no browser on an iPhone or iPad does.

Open this page as http://localhost:8090. Browsers only allow USB on pages from this computer (localhost) or from https.

1. Get the phone ready

  1. Factory reset the phone: Settings > System > Reset options > Erase all data.
  2. In the setup wizard, skip every account: don't add a Google account yet. You add the parent's own account after Belay is set up.
  3. Turn on USB debugging: Settings > About phone > tap "Build number" 7 times. Then Settings > System > Developer options > turn on "USB debugging".
  4. Plug the phone into this computer with a cable that carries data (some only charge).

If adb or Android Studio runs on this computer, close it or run adb kill-server first: only one program at a time can use the phone's USB debugging.

3. Your family's server (you can do this later)

On your Belay server's parent page, choose Add a phone, give it a name, and copy its address and code here. The code works once, for 30 minutes. If you leave both empty, connect the phone later from Belay's own screen on the phone.

4. Connect the phone

Your browser lists the phones it can see: choose yours. Then look at the phone: it asks "Allow USB debugging?". Tick "Always allow from this computer" (so the restart doesn't ask again) and tap Allow.
